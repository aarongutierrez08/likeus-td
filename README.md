# Likeus TD

Tower defense cooperativo para navegador, hasta 8 jugadores. Se juega en https://likeus-td.pages.dev (modo solo) o en https://likeus-td.pages.dev/?mode=coop para crear una sala y compartir el código.

- Guía técnica: [docs/guia-tecnica.md](docs/guia-tecnica.md).
- Decisiones de arquitectura: [docs/adr/README.md](docs/adr/README.md).

```
pnpm install
pnpm dev        # cliente en :5173 y server en :2567
pnpm check      # tipos, lint y formato
pnpm test       # tests de sim y de server
```
